# Tracker Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Hedef:** Giriş yapmış kullanıcının karakter, corporation ve alliance
kısayol listesi: header'da TRACKER menüsü, profil sayfalarında ve killmail
detayında ekleme/çıkarma, avatar menüsünde kendi killmail'lerine link.

**Mimari:** Yeni `tracked_entities` tablosu, elle eklenen kayıtları tutar.
Otomatik kayıtlar (kendi corp/alliance) her okumada `characters` satırından
hesaplanır. Backend'de düz fonksiyonlu bir `tracker.service.ts` var,
resolver'lar yalnızca orkestrasyon yapar. Ön yüzde bir `useTracker` hook'u,
iki ortak bileşen (`TrackButton`, `TrackDialog`) ve bir `TrackerMenu` var.

**Teknoloji:** Prisma (elle yazılmış migration + `migrate deploy`), GraphQL
Yoga + codegen, Next.js App Router, Apollo Client, Headless UI (React), Vitest

- Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-30-tracker-design.md`

## Genel kısıtlar

- Yalnızca yarn; npm asla.
- `prisma migrate dev` / `migrate reset` asla. Migration CLAUDE.md'deki
  _Database migrations_ yordamıyla yazılır, `npx prisma migrate deploy` ile
  uygulanır. Öncesi ve sonrası beş elle yönetilen tablonun satır sayısı
  alınır.
- Üretilmiş dosyalar elle düzenlenmez: `backend/src/generated-types.ts`,
  `backend/src/generated-schema.graphql`, `frontend/src/generated/graphql.ts`.
- API tarafı `@services/prisma` kullanır, `prisma-worker` değil.
- Kullanıcı başına elle eklenen kayıt sınırı: **200**. Otomatik kayıtlar
  sınıra sayılmaz.
- `myTracker` response cache'e girmez: `backend/src/config/cache.ts` içinde
  `'Query.myTracker': 0`.
- Arayüz metinleri İngilizce. Spec'teki sabit metinler: `TRACKER`,
  `CORPORATIONS`, `ALLIANCES`, `CHARACTERS`, `+ TRACK`, `TRACKING`, `UNTRACK`,
  `TRACK…`, `VICTIM`, `ATTACKERS`, `final blow`, `top damage`. Otomatik etiket
  `AUTO-TRACKED`. Avatar linki `MY KILLMAILS`. Boş liste notu: `Add
characters, corporations and alliances with the TRACK button on their
pages.`
- Focus ring yok: odak hover'ın görünümüyle gösterilir. Rozetler tek gri
  (`IconBadge`). Stil `buttons.css` sınıflarıyla.
- Commit mesajları İngilizce, `type(scope):` sonrası küçük harf, Claude imzası
  yok.

1. **Silinmiş ya da henüz olmayan bir entity satırı.** Takipteki bir ID'nin
   loader'ı `null` dönerse kayıt sessizce atlanır; `myTracker` hata vermez.

true` olarak gösterir. Corp değiştirince eski corp elle eklenmiş kayıt

   karakter sekmesine girmez, corp'u `null` ise corp sekmesine girmez. Test:

- Üretir (şema):

```graphql
enum TrackedEntityType {
  CHARACTER
  CORPORATION
  ALLIANCE
}
type TrackedCharacter {
  automatic: Boolean!
  character: Character!
}
type TrackedCorporation {
  automatic: Boolean!
  corporation: Corporation!
}
type TrackedAlliance {
  automatic: Boolean!
  alliance: Alliance!
}
type Tracker {
  characters: [TrackedCharacter!]!
  corporations: [TrackedCorporation!]!
  alliances: [TrackedAlliance!]!
}
extend type Query {
  myTracker: Tracker!
}
extend type Mutation {
  track(type: TrackedEntityType!, id: Int!): Boolean!
  untrack(type: TrackedEntityType!, id: Int!): Boolean!
}
```

- `myTracker`: girişsiz `GraphQLError` `extensions.code: 'UNAUTHENTICATED'`.
  Ref'leri loader'larla çözer, `null` dönenleri atlar; tarihleri mevcut
  resolver'lardaki gibi ISO'ya çevirir (`birthday`, `date_founded`,
  `updated_at`; bkz. `resolvers/character/queries.ts:27-29`,
  `resolvers/alliance/queries.ts:27`). Grup içi sıra: otomatik önce, sonra
  isim.
- `track` / `untrack`: başarıda `true`. `TrackerError` → `GraphQLError`,
  `extensions.code: 'BAD_USER_INPUT'`, `extensions.reason: <kod>`.

- [ ] **Adım 1:** Şemayı yaz, `yarn workspace backend codegen`.
- [ ] **Adım 2: Başarısız testler:** girişsiz `myTracker` → `UNAUTHENTICATED`;
